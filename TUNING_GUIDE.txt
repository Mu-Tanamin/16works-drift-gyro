# คู่มือการปรับจูนพารามิเตอร์ไจโรสโคป (ESP32-C3 RC Drift Gyroscope Tuning Guide)

ระบบไจโรสโคปนี้ทำงานบนพื้นฐาน **Pure Normal Rate Mode (P + D Control)** พร้อมอัลกอริทึมพิเศษสำหรับรถสเกลเล็ก (1/24 – 1/28 Micro RC Drift) เช่น เซอร์โว AFRC D2114TG-S (333Hz)

---

## สรุปภาพรวมค่าพารามิเตอร์และค่าเริ่มต้น (Default Overview)

| พารามิเตอร์ (บนหน้าเว็บ) | ค่าเริ่มต้น (Default) | ช่วงที่แนะนำ (Tuning Range) | หน่วย | หน้าที่หลัก |
| :--- | :---: | :---: | :---: | :--- |
| **P-Gain (Rate Authority)** | `2.6` | `2.0 - 3.5` | - | แรงเด้งสวนหลักตามความเร็วกวาดท้าย (Counter-steer Authority) |
| **D-Gain (Predictive Acceleration)** | `0.15` | `0.05 - 0.30` | - | คาดเดาความเร่งการหมุน ลดอาการท้ายดีดกลับ (Damping & Stability) |
| **S-Curve Exponential** | `20 %` | `10 % - 45 %` | `%` | นุ่มนวลตรงกลาง แต่เพิ่มแรงดึงทวีคูณตอนสะบัดมุมกว้าง |
| **Steering Priority** | `35 %` | `25 % - 60 %` | `%` | คืนอำนาจเลี้ยวให้คนขับตอนหักสุด ช่วยให้สลับไลน์ได้พริ้ว |
| **Snap Speed** | `4500` | `3500 - 7000` | µs/s | ความเร็วการเด้งสวนของเซอร์โวตอนแก้อาการสปิน (สูงสุด 8000) |
| **Return Speed** | `2200` | `1600 - 3200` | µs/s | ความเร็วการคืนพวงมาลัยกลับนุ่มนวล ป้องกันอาการท้ายสะบัดข้าม (สูงสุด 5000) |
| **Damper** | `0.50` | `0.35 - 0.70` | - | กรองความถี่ต่ำ ลดการสั่นสะเทือนจากแชสซี/มอเตอร์ (ค่าต่ำลง = หน่วงขึ้น) |
| **Deadband** | `0.50` | `0.30 - 1.00` | deg/s | ตัด Noise ตอนรถอยู่นิ่ง ป้องกันเซอร์โวสั่นคราง |
| **Servo Sub-Trim** | `0` | `-150 ถึง +150` | µs | ชดเชยศูนย์ล้อหน้าตรง 100% สำหรับรถ Direct Steering |
| **EPA Left / Right** | `1100 / 1900` | ตามกลไกแชสซี | µs | ลิมิตมุมเลี้ยวสูงสุด ป้องกันเซอร์โวยันติด (บันทึกด้วย SAVE CONFIG) |
| **Servo Frequency** | `333` | `333 หรือ 50` | Hz | ความถี่สัญญาณเซอร์โว (333Hz สำหรับ AFRC Digital) |
| **Direction** | `Normal` | Normal/Reversed | - | ทิศทางการแก้พวงมาลัย (เอียงซ้าย ล้อต้องสวนขวา) |

---

## รายละเอียดและการวิเคราะห์อาการแต่ละค่า (Deep-Dive Tuning)

### 1. P-Gain (Rate Authority)
* **หน้าที่**: เป็นค่าน้ำหนักหลักในการคำนวณแรงหักล้อหน้าสวนทาง (Counter-steer) ตามความเร็วการหมุนตัวของรถ
* **อาการเมื่อตั้งต่ำเกินไป (< 1.8)**: รถหมุนสปินง่าย ล้อหน้าไม่ยอมดึงสวนช่วย คนขับต้องคอยสาวพวงมาลัยช่วยเยอะ
* **อาการเมื่อตั้งสูงเกินไป (> 3.8)**: ล้อหน้าสะบัดส่ายไปมา (Fish-tailing / Hunting) รถดิ้นเหมือนงูบนทางตรง
* **วิธีปรับ**: ตั้งไว้ที่ `2.6` แล้วใช้ลูกบิด CH3 ที่รีโมทช่วยเกลี่ย ถ้ายังสปินให้เพิ่ม P-Gain ทีละ `+0.2`

---

### 2. D-Gain (Predictive Acceleration)
* **หน้าที่**: คอยจับ "อัตราเร่งของการหมุน" เพื่อแตะเบรกเซอร์โวล่วงหน้า ไม่ให้พวงมาลัยหมุนเลยจุดสมดุล (Overshoot)
* **อาการเมื่อตั้งต่ำเกินไป (< 0.05)**: เวลาหลุดสไลด์แล้วแก้อาการ ท้ายรถจะสะบัดเหวี่ยงข้ามไปอีกฝั่งทันที (Snap Oversteer)
* **อาการเมื่อตั้งสูงเกินไป (> 0.35)**: เซอร์โวจะสั่นจี่ๆ หรือมีอาการกระตุกถี่ๆ เวลากดคันเร่งเต็มหรือพื้นผิวสนามสั่น
* **วิธีปรับ**: ถ้าเข้าโค้งแล้วท้ายส่ายดิ้นไม่ยอมนิ่ง ให้เพิ่ม D-Gain ขึ้นทีละ `+0.05`

---

### 3. S-Curve Exponential (แสดงผลเป็น %)
* **หน้าที่**: ปรับฟีลลิ่งพวงมาลัย ให้ช่วงมุมดริฟท์แคบๆ หรือวิ่งทางตรง พวงมาลัยจะไม่ไวเกินไป แต่พอกวาดท้ายมุมกว้าง ไจโรจะเพิ่มแรงดึงทวีคูณ
* **อาการเมื่อตั้งต่ำไป (0 % Linear)**: พวงมาลัยตึงและไวเกินไปบนทางตรง รถตอบสนองคมจัด
* **อาการเมื่อตั้งสูงเกินไป (> 55 %)**: ช่วงดริฟท์มุมแคบไจโรไม่ค่อยช่วย แต่พอมุมเริ่มเยอะ ไจโรจะกระชากดึงแรงจนตกใจ
* **วิธีปรับ**: 
  - **สนามกว้างความเร็วสูง / ลื่นไหล (Sweeper Track)**: แนะนำ **`10 % - 25 %`**
  - **สนามแคบเทคนิคอล / ดริฟท์สไตล์โชว์องศา (Tight / Show Drift)**: แนะนำ **`25 % - 45 %`**

---

### 4. Steering Priority (แสดงผลเป็น %)
* **หน้าที่**: ลดแรงต้านของไจโรลงเมื่อคนขับหักพวงมาลัยที่รีโมทสุด เพื่อให้สามารถสะบัดเปลี่ยนทิศทาง (Flick / Quick Transition) ได้ทันที
* **อาการเมื่อตั้งต่ำไป (< 15 %)**: ไจโรขืนมือตลอดเวลา พวงมาลัยหนัก รถไม่ยอมพลิกหน้าเวลาจะเปลี่ยนไลน์
* **อาการเมื่อตั้งสูงเกินไป (> 70 %)**: ตอนหักเลี้ยวสุด ไจโรจะหยุดทำงานเกือบหมด ถ้ารถสะบัดแรงอาจสปินหลุดทันที
* **วิธีปรับ**: 
  - **สายสลับไลน์ไว / พลิกตัวเร็ว (Aggressive Transition)**: แนะนำ **`45 % - 60 %`**
  - **สายดริฟท์นุ่มนวล / เกาะโค้งนิ่ง (Smooth / Stable Grip)**: แนะนำ **`25 % - 40 %`**

---

### 5. Snap Speed (ความเร็วล้อเด้งสวน) & Return Speed (ความเร็วล้อคืนตัว)
* **หน้าที่ (Asymmetric Slew Rate — คุมเฉพาะแรงแก้ของไจโร ไม่หน่วงมือคนขับ)**:
  - **Snap Speed**: ควบคุมความเร็วตอนล้อ "เด้งสวน" แก้อาการ เพื่อหยุดการสปินและสลับฝั่ง (Transition)
  - **Return Speed**: ควบคุมความเร็วตอนล้อ "คืนตัวกลับมาตรง" อย่างนุ่มนวล เพื่อป้องกันท้ายสะบัดดีดกลับ (Tank-slapper)
* **สูตรสำเร็จ**: Snap Speed ต้องเร็วกว่า Return Speed เสมอ (ประมาณ 1.5 - 2.0 เท่า)
  - ค่าแนะนำมาตรฐาน: Snap = `4500`, Return = `2200`
  - ถ้าท้ายดีดกลับแรงตอนคืนล้อ: ให้ลด Return Speed ลงเหลือ `1600 - 1900`
  - ถ้ารถแก้อาการช้าไปจนสปิน (หรือทำ Reverse Entry): ให้เพิ่ม Snap Speed ขึ้นเป็น `5500 - 7500`

---

### 6. Damper (Low-Pass Filter) & Deadband
* **Damper (0.50)**:
  - ช่วยกรองแรงสั่นสะเทือนทางกล (Vibration) จากมอเตอร์ความเร็วรอบสูง (ค่ามากขึ้น = ตอบสนองไวขึ้น, ค่าน้อยลง = นุ่มหน่วงขึ้น)
  - ถ้ารถสั่น/มีเสียงครางเวลาเร่งรอบสูง: ให้ลด Damper ลงเหลือ `0.35 - 0.40`
* **Deadband (0.50 deg/s)**:
  - ตัดสัญญาณรบกวนตอนรถจอดนิ่งๆ เพื่อให้เซอร์โวหยุดพัก ไม่กินไฟและไม่ร้อน
  - ถ้าจอดเฉยๆ แล้วล้อหน้ากระตุกเบาๆ: ให้ขยับ Deadband ขึ้นเป็น `0.60 - 0.80`

---

### 7. Servo Sub-Trim & EPA (Direct Steering Setup)
* **กฎสำคัญสำหรับ Direct Steering**:
  - **ห้ามปรับ Sub-Trim หรือ Trim พวงมาลัยที่รีโมทเด็ดขาด** (ต้องปล่อยไว้ที่ 0 หรือ 1500 µs เสมอ เพื่อไม่ให้ Steering Priority เพี้ยน)
  - ให้ปรับแก้ศูนย์ล้อหน้าตรงด้วย **`Servo Sub-Trim`** บนหน้าเว็บกล่องไจโรเท่านั้น
* **การตั้ง EPA (Limit Left / Right)**:
  - เลื่อนแถบตั้ง Limit ซ้ายและขวาบนหน้าเว็บตามระยะเลี้ยวสูงสุดของแชสซี
  - ปรับให้เลี้ยวสุดโดย **ไม่ยันกลไกคอม้าหรือปีกนก** แล้วกดปุ่ม **SAVE CONFIG** เพื่อบันทึกค่าลงหน่วยความจำ

---
