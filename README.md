# 16WORKs Drift Gyro (ESP32-C3 Pure Normal Rate Edition)

ระบบช่วยดริฟท์ควบคุมหักเลี้ยวแก้อาการ (Counter-Steer) สำหรับรถดริฟท์บังคับวิทยุ (Micro RC Drift 1/24 - 1/28) พัฒนาบน **ESP32-C3 Super Mini** + **MPU6050** ร่วมกับเซอร์โวดิจิตอลความเร็วสูง **AFRC D2114TG-S (333Hz)** 

เวอร์ชันนี้ใช้ระบบ **Pure Normal Rate Mode (P+D)** ล้วนๆ ตามสไตล์โปรดริฟท์ ให้ฟิลลิ่งพวงมาลัยคืนตัวธรรมชาติ ควบคุมท้ายรถด้วยคันเร่งได้อย่างแม่นยำ พร้อมหน้าเว็บจูนค่าผ่าน **Wi-Fi Web Tuner** ข้างสนามได้ทันที!

---

## 🎮 การควบคุม Gain ผ่านรีโมท (CH3)

สัญญาณพัลส์จากช่อง CH3 ของรีโมท (1000 - 2000 µs) ถูกตั้งค่าให้จุดกึ่งกลาง (1500 µs หรือเลข 0 บนรีโมท) เป็น **0% (ปิดไจโร)** และเมื่อหมุนไปฝั่งบวกหรือฝั่งลบ จะเพิ่มค่า Gain เท่ากันทั้งสองฝั่ง (0% - 100%):

```
  CH3 Signal จากรีโมท (1000 µs ถึง 2000 µs)
 ◄───────────────[ 1000 µs ]──────────────[ 1500 µs ]──────────────[ 2000 µs ]──────────────►
                   -100 %                     0                     +100 %
                (บนรีโมท)                 (บนรีโมท)                (บนรีโมท)
                   100 %                     0 %                     100 %
                (Gain ไจโร)               (ปิดไจโร)               (Gain ไจโร)
```

* **1500 µs (ตรงกลาง 0 บนรีโมท)** $\to$ Gain 0% (ปิดไจโร)
* **หมุนไปฝั่งบวก (1500 ถึง 2000 µs)** $\to$ เพิ่ม Gain จาก 0% ถึง 100%
* **หมุนไปฝั่งลบ (1500 ถึง 1000 µs)** $\to$ เพิ่ม Gain จาก 0% ถึง 100% เท่ากัน

   * **Wi-Fi SSID**: `ESP32-DRIFT-GYRO`
   * **Password**: `12345678`

4. หน้าเว็บจะแสดงค่า Real-time ทั้ง Steering (CH1), Servo Output, ค่า Gyro Z, และ Gain ปัจจุบัน พร้อม Sliders ให้ปรับแต่งได้ทันที

## 🎛️ พารามิเตอร์ระดับ Pro-Level ที่ปรับได้บนหน้าเว็บ

* **P-Gain**: ความไวหลักในการดึงพวงมาลัยแก้อาการ
* **D-Gain (Predictive)**: คำนวณความเร่งการหมุน ล้อหน้าเริ่มแก้อาการก่อนรถเสียหลัก
* **S-Curve Expo**: Curve การตอบสนอง (ตรงกลางนุ่มนวล สะบัดแรงดึงทวีคูณ)
* **Steering Priority**: สัดส่วนลดทอนไจโรตอนคนขับหักเลี้ยวสุด (ช่วยให้สลับไลน์ Flick/Transition ได้คล่อง ไม่สู้มือ)
* **Snap Speed**: ความเร็วล้อเด้งสวนแก้อาการ ($\mu\text{s/s}$) กันรถสปิน
* **Return Speed**: ความเร็วล้อคืนตัวกลับศูนย์ ($\mu\text{s/s}$) กันอาการท้ายดีดกลับ
* **Damper Filter**: กรองแรงสั่นสะเทือนจากมอเตอร์รอบจัด ป้องกันเซอร์โวสั่นรัว
* **Deadband**: ตัด Noise ที่จุดกึ่งกลาง ป้องกันเซอร์โวครางตอนรถอยู่นิ่ง
* **Servo Sub-Trim (Direct Steering)**: ปรับเยื้องศูนย์เซอร์โว ($\pm 150\,\mu\text{s}$) เพื่อให้ล้อหน้าตรง 0 Toe เป๊ะ โดยไม่ต้องใช้ Sub-Trim ที่รีโมท
* **EPA Left / Right (Real-time Live Tuning)**: ตั้งจุดเลี้ยวซ้ายสุด / ขวาสุดแบบ Real-time (ขณะเลื่อนสไลเดอร์ ล้อหน้าจะเลี้ยวไปค้างที่ตำแหน่ง Limit ทันทีเพื่อให้ดูระยะเลี้ยวจริง ป้องกันชุดเลี้ยวติดขัด/หัก)
* **Servo Frequency**: 333Hz (AFRC D2114TG-S Pro) หรือ 50Hz (Standard)

## 📌 แผนผังการต่อวงจร (ESP32-C3 Super Mini Pinout)

| ขา ESP32-C3 | ขาอุปกรณ์ | หน้าที่การทำงาน |
| :--- | :--- | :--- |
| **GPIO 6** | MPU6050 `SDA` | I2C Data (400kHz Fast Mode) |
| **GPIO 7** | MPU6050 `SCL` | I2C Clock |
| **GPIO 2** | Receiver `CH1` | สัญญาณเลี้ยวจากรีซีฟเวอร์ (Steering Input) |
| **GPIO 3** | Receiver `CH3` | สัญญาณปรับ Gain จากวิทยุ (1000 - 2000 µs) |
| **GPIO 4** | Servo Signal | สัญญาณสั่งเซอร์โวดิจิตอล AFRC (333Hz PWM) |
| **GPIO 8** | Onboard LED | ไฟ LED สีน้ำเงินบนบอร์ดแสดงสถานะ |
| **GPIO 9** | Onboard BOOT | ปุ่มกดบนบอร์ดสำหรับตั้งค่าแบบ Offline (กดค้าง > 2s) |
| **3.3V / 5V** | VCC | เลี้ยง MPU6050 (3.3V) และ Servo (5V จาก BEC) |
| **GND** | GND | กราวด์ร่วมกันทุกอุปกรณ์ |

## ❄️ ระบบจัดการความร้อนและพลังงาน (Thermal & Power Management)

เพื่อป้องกันไม่ให้ชิป ESP32-C3 Super Mini ร้อนจัดบนแชสซีรถเล็ก 1/28 ระบบได้ติดตั้ง 3 กลไกลดความร้อนอัตโนมัติ:

1. **CPU Frequency Scaling (80 MHz)**:
   * ลดความเร็วคล็อก CPU จาก 160MHz เหลือ 80MHz ช่วยลดการกินไฟและความร้อนลงทันที ~40% โดยที่การตอบสนองของลูปไจโร 250Hz และเซอร์โว 333Hz ยังแม่นยำเต็ม 100%
2. **Low-Power Wi-Fi TX Power (8.5 dBm)**:
   * ลดกำลังส่งคลื่นวิทยุลงจาก 20 dBm (100mW) เหลือ 8.5 dBm (~7mW) ช่วยลดความร้อนของภาคขยายสัญญาณ RF อย่างมาก โดยยังเชื่อมต่อจูนได้ไกล 5–10 เมตรรอบตัวรถ
3. **Smart Wi-Fi Sleep & On-Demand Toggle**:
   * **Auto-Sleep**: หากไม่มีมือถือเชื่อมต่อจูนเกิน 90 วินาทีหลังเปิดสวิตช์ Wi-Fi จะดับตัวเองอัตโนมัติ (กระแสไฟลดลงเหลือเพียง ~25mA บอร์ดจะเย็นเฉียบทันที)
   * **กดปุ่มสั้นบนบอร์ด (BOOT GPIO 9)**: กดคลิกสั้น 1 ครั้ง เพื่อสลับเปิด หรือ ปิด Wi-Fi ได้ทันทีขณะรถจอด
   * **ปุ่มบนหน้าเว็บ**: กดปุ่ม *"❄️ ปิด Wi-Fi เพื่อลดความร้อน (เข้าโหมดขับ)"* บนหน้า Dashboard เพื่อตัด Wi-Fi ทันทีหลังจูนเสร็จ
