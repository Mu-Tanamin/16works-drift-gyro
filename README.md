# 16WORKs Drift Gyro (ESP32-C3 Pure Normal Rate Edition)

ระบบช่วยดริฟท์ควบคุมหักเลี้ยวแก้อาการ (Counter-Steer) สำหรับรถดริฟท์บังคับวิทยุ (Micro RC Drift 1/24 - 1/28) พัฒนาบน **ESP32-C3 Super Mini** + **MPU6050** ร่วมกับเซอร์โวดิจิตอลความเร็วสูง **AFRC D2114TG-S (333Hz)**

เวอร์ชันนี้ (V3.4) ใช้ระบบ **Pure Normal Rate Mode (P+D)** ล้วนๆ ตามสไตล์โปรดริฟท์ พร้อมหน้าเว็บจูนค่าผ่าน **BLE 5.0 Web Bluetooth Tuner** ไม่ต้องสลับ Wi-Fi

---

## 🎮 การควบคุม Gain ผ่านรีโมท (CH3)

สัญญาณพัลส์จากช่อง CH3 ของรีโมท (1000 - 2000 µs) ถูกตั้งค่าให้จุดกึ่งกลาง (1500 µs หรือเลข 0 บนรีโมท) มี Deadband ±10 µs = **0% (ปิดไจโร)** และเมื่อหมุนไปฝั่งบวกหรือฝั่งลบ จะเพิ่มค่า Gain เท่ากันทั้งสองฝั่ง (0% - 100% ที่ ~1990 / ~1010 µs):

```
  CH3 Signal จากรีโมท (1000 µs ถึง 2000 µs)
 ◄───────────────[ 1000 µs ]──────────────[ 1500 µs ]──────────────[ 2000 µs ]──────────────►
                   -100 %                     0                     +100 %
                (บนรีโมท)                 (บนรีโมท)                (บนรีโมท)
                   100 %                     0 %                     100 %
                (Gain ไจโร)               (ปิดไจโร)               (Gain ไจโร)
```

## 📱 วิธีเชื่อมต่อและปรับจูนผ่านมือถือ (BLE 5.0 Web Bluetooth)

1. **เปิดสวิตช์รถ**: วางรถให้นิ่งสนิทบนพื้น ~1.5 วินาทีเพื่อให้ระบบ Auto-Calibrate แกน Z (หากรถขยับระหว่างบูต ระบบจะลองใหม่จนกว่ารถจะนิ่ง)
2. **เปิดหน้าเว็บจูนค่าผ่าน HTTPS** (เช่น GitHub Pages หรือ `localhost` — Web Bluetooth ไม่รองรับการเปิดไฟล์ `file://` โดยตรง):
   * **Android / Windows / macOS**: ใช้เบราว์เซอร์ **Chrome** หรือ Edge
   * **iPhone / iPad (iOS)**: ใช้แอปเบราว์เซอร์ **Bluefy** (รองรับ Web Bluetooth)
3. **กดปุ่ม `CONNECT BLE`** บนหน้าเว็บ แล้วเลือกอุปกรณ์ชื่อ **`16WORKs-GYRO-XXXX`** (รหัส 4 หลักท้ายแยกตาม MAC ของแต่ละบอร์ด)
4. **Tuning PIN**: ค่าเริ่มต้นคือ `1616` (สามารถกดปุ่ม `CHANGE` ในหน้าเว็บเพื่อตั้งรหัสใหม่ของรถตัวเองได้ เพื่อกันคนอื่นในสนามเข้ามาแก้ค่า และระบบจะบล็อกการแก้ค่าอัตโนมัติขณะรถกำลังวิ่ง/หมุนพวงมาลัย)

## 🎛️ พารามิเตอร์ที่ปรับได้บนหน้าเว็บ

* **P-Gain**: ความไวหลักในการดึงพวงมาลัยแก้อาการ
* **D-Gain (Predictive)**: คำนวณความเร่งการหมุน (`deg/s²`) ช่วยเบรกล้อหน้าล่วงหน้าก่อนรถโอเวอร์ชูต
* **S-Curve Expo**: Curve การตอบสนอง (ตรงกลางนุ่มนวล สะบัดแรงดึงทวีคูณ)
* **Steering Priority**: สัดส่วนลดทอนไจโรตอนคนขับหักเลี้ยวสุด (ช่วยให้สลับไลน์ Flick/Transition ได้คล่อง)
* **Snap Speed / Return Speed**: ความเร็วเด้งสวนและคืนตัวแบบ Asymmetric (คุมเฉพาะแรงแก้ของไจโร ไม่หน่วงมือคนขับ)
* **Damper Filter & Deadband**: กรองแรงสั่นสะเทือนและตัด Noise ตอนรถจอดนิ่ง
* **Servo Sub-Trim (Live)**: ปรับเยื้องศูนย์เซอร์โว ($\pm 150\,\mu\text{s}$) แบบเห็นผลทันที เพื่อให้ล้อหน้าตรง 0 Toe โดยไม่ต้องใช้ Trim ที่รีโมท (กด `SAVE CONFIG` เพื่อบันทึกลง Flash)
* **EPA Left / Right**: ตั้งลิมิตระยะเลี้ยวซ้ายสุด / ขวาสุด (`800 - 2200 µs`) แล้วกด `SAVE CONFIG` เพื่อบันทึก
* **Servo Frequency & Direction**: 333Hz (AFRC D2114TG-S) หรือ 50Hz และสลับ Normal / Reversed

---

## 🔘 การใช้งานปุ่ม BOOT บนบอร์ด (GPIO 9)

* **กดสั้น (50–800 ms)**: สั่ง **Zero Gyro** (Calibrate แกน Z ใหม่ข้างสนาม — ต้องวางรถนิ่ง)
* **กดค้าง > 2 วินาที**: เข้าโหมดตั้งค่าแบบ Offline (`EPA Left` → กดสั้น → `EPA Right` → กดสั้น → `Direction` → กดสั้นเพื่อบันทึก)
* **กดค้าง > 6 วินาที**: รีเซ็ต **Tuning PIN** กลับเป็นค่าเริ่มต้น (`1616`) กรณีลืมรหัส

## 📌 แผนผังการต่อวงจร (ESP32-C3 Super Mini Pinout)

| ขา ESP32-C3 | ขาอุปกรณ์ | หน้าที่การทำงาน |
| :--- | :--- | :--- |
| **GPIO 6** | MPU6050 `SDA` | I2C Data (400kHz Fast Mode) |
| **GPIO 7** | MPU6050 `SCL` | I2C Clock |
| **GPIO 2** | Receiver `CH1` | สัญญาณเลี้ยวจากรีซีฟเวอร์ (Steering Input) |
| **GPIO 3** | Receiver `CH3` | สัญญาณปรับ Gain จากวิทยุ (1000 - 2000 µs) |
| **GPIO 4** | Servo Signal | สัญญาณสั่งเซอร์โวดิจิตอล AFRC (333Hz PWM) |
| **GPIO 8** | Onboard LED | ไฟ LED สีน้ำเงินบนบอร์ดแสดงสถานะ (Active LOW) |
| **GPIO 9** | Onboard BOOT | ปุ่มกดบนบอร์ดสำหรับ Zero Gyro / Offline Setup / PIN Reset |
| **3.3V / 5V** | VCC | เลี้ยง MPU6050 (3.3V) และ Servo (5V จาก BEC) |
| **GND** | GND | กราวด์ร่วมกันทุกอุปกรณ์ |

## ❄️ ระบบจัดการความร้อน พลังงาน และความปลอดภัย

1. **CPU Frequency Scaling (80 MHz)**: ลดความเร็วคล็อก CPU เหลือ 80MHz ลดการกินไฟและความร้อนบนบอร์ด Super Mini
2. **Ultra-Low-Power BLE 5.0 (0 dBm)**: ใช้ BLE กำลังส่ง 0 dBm (`ESP_PWR_LVL_N0`) แทน Wi-Fi เย็นเฉียบตลอดการขับขี่
3. **I2C Fault Pass-Through**: หากสาย MPU6050 หลุดหรือบัส I2C มีปัญหา (`timeout 3ms`) ระบบจะตัดไจโรเป็น 0 และส่งพวงมาลัยคนขับตรงไปที่เซอร์โวทันที พร้อมกะพริบไฟ LED เตือน
4. **Arduino IDE Build Requirements**: ใช้ **ESP32 Arduino Core 3.x** ขึ้นไป, Board: `ESP32C3 Dev Module`, Partition Scheme: `Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)`, USB CDC On Boot: `Enabled`
